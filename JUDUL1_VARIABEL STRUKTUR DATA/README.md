Judul Program: Bagaimana Cara Sederhana Menginput Nilai Mahasiswa

   Program Python ini berfungsi sebagai sistem sederhana untuk menginput, menyimpan, menampilkan, dan menghitung rata-rata nilai mahasiswa. User dapat memilih menu untuk melihat tabel nilai, memasukkan atau memperbarui nilai setiap mata kuliah, menghitung rata-rata per mahasiswa, atau keluar dari program.
  Algoritma struktur data yang digunakan adalah dengan memanfaatkan struktur data list dua dimensi (2D list). Setiap baris dalam list mewakili seorang mahasiswa, sedangkan setiap kolom mewakili mata kuliah. Proses input nilai dilakukan dengan nested loop (loop bersarang) untuk mengisi data ke dalam list 2D.
